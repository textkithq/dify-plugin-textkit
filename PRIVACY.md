# Privacy policy

This TextKit plugin for Dify processes your TextKit API key and what you pass to its tools: phone numbers, message text, sender numbers, list filters, app names and one-time verification codes. These can be personal data.

Dify stores the API key in its credential store. The plugin holds all of this data in memory while a tool runs. It stores nothing itself, and it does not collect analytics or log message content, phone numbers, codes or keys.

The plugin sends this data only to TextKit at `https://api.jointextkit.com` over HTTPS, and returns TextKit's responses to Dify. TextKit processes the data under the [TextKit privacy policy](https://jointextkit.com/privacy), and mobile carriers process texts to deliver them. Dify's own settings decide how long it keeps workflow inputs, outputs and logs.

Contact: support@jointextkit.com
